Note for AI agents and other programs

This is SharedMarkdown: Markdown documents that people edit together in real time, without accounts. Anyone with a document's link can read and edit it, and so can you, over plain HTTP. People who have the document open see your edits immediately.

  • Read a document as Markdown: GET its link with ".md" appended, for example https://sharedmarkdown.com/AbCdEf123456.md (add ?lines=10-40 for some lines, &numbered=1 for line numbers).
  • Edit it: PATCH the same .md URL with JSON {"edits":[{"old":"exact text to replace","new":"replacement"}]}. Each "old" must appear exactly once in the document. {"append":"text"} adds to the end.
  • Replace all of it: PUT the .md URL with the new Markdown as the body and the header If-Match set to the ETag from your GET.
  • Create a new document: POST Markdown to https://sharedmarkdown.com/new.md. The answer contains its edit link and a read-only link.
  • Links that start with /r/ are read-only.

Full reference with examples: https://sharedmarkdown.com/llms.txt
